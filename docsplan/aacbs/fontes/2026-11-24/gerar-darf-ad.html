Gerar DARF para Recolhimento de CBS como Adquirente

1. Objetivo

Gerar documento de arrecadação para recolhimento de CBS na condição de adquirente (RAD).

2. Histórico de versão

Data Versão Descrição
13/11/2026 1.0 Versão inicial

3. Regras de retorno

Esta API funciona em modo síncrono, gerando documentos de arrecadação de acordo com os valores processados pela Apuração Assistida de CBS.

4. Endpoint da api

  • URL de Produção:
    • https://api.receitafederal.gov.br/apuracao-cbs/v2/rad/{cnpj}

4.1 Campos de Entrada

Campo Formato Descrição
cnpj String (14) CNPJ base informado no path.

4.2 Header

Campo Formato Descrição
Authorization String Bearer <token de acesso>, informado na requisição.

4.3 Request Body

Campo Objeto da cardinalidade Nível Cardinalidade Formato Descrição
body raiz (body) 1 1:N Array de Object Lista de solicitações de geração de DARF, uma por DF-e.
chaveDFE body 2 1:1 String (100) Chave DF-e utilizada para geração do documento de arrecadação.
opcaoPagamento body 2 1:1 String Opção de pagamento para emissão do DARF. Valores possíveis: PAGAMENTO_PARCIAL e PAGAMENTO_TOTAL.
valorDarfParcial body 2 0:1 Number (18,2) Valor parcial do DARF, obrigatório quando opcaoPagamento = PAGAMENTO_PARCIAL. Ignorado quando PAGAMENTO_TOTAL

4.4 Acionar o endpoint

  1. Substitua $TOKEN pelo valor de access_token.
  2. Substitua {cnpj} pelo CNPJ com 14 dígitos.

Método: POST

Exemplo de chamada (Produção)

curl --location --request POST 'https://api.receitafederal.gov.br/apuracao-cbs/v2/rad/{cnpj}' \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '[
    {"chaveDFE": "35260912345678000123550010000000011000000010",
    "opcaoPagamento": "PAGAMENTO_PARCIAL",
    "valorDarfParcial": 1500.75
    },
    {
    "chaveDFE": "35260912345678000123550010000000011000000011",
    "opcaoPagamento": "PAGAMENTO_PARCIAL",
    "valorDarfParcial": 500.00
     },
    {
    "chaveDFE": "35260912345678000123550010000000011000000012",
    "opcaoPagamento": "PAGAMENTO_TOTAL"
    }
  ]'

Exemplo de chamada (Pagamento parcial)

curl --location --request POST 'https://api.receitafederal.gov.br/apuracao-cbs/v2/rad/12345678' \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '[    
    {
    "chaveDFE": "35260912345678000123550010000000011000000011",
    "opcaoPagamento": "PAGAMENTO_PARCIAL",
    "valorDarfParcial": 500.00
     }
  ]'

4.5 Campos Retornados

Campo Objeto da cardinalidade Nível Card. Formato Descrição
cdRetorno raiz 1 1:1 String Código de retorno da operação:
DARF_GERADO = Documento fiscal encontrado, ainda não extinto e DARF gerado com sucesso
DFE_NAO_ENCONTRADO = Documento fiscal não encontrado ou não vinculado ao CNPJ requisitante
VALOR_PARCIAL_SUPERIOR_DFE = Valor informado para pagamento parcial é superior ao valor total do documento fiscal informado
CNPJ_NAO_ADQUIRENTE = CNPJ não é o adquirente da DF-e
DADOS_DE_ENTRADA_INVALIDOS = dados inválidos <lista de dados inválidos>
darf raiz 1 1:1 Object Grupo com dados do DARF (presente quando cdRetorno = DARF_GERADO).
chavePIX darf 2 1:1 String Chave PIX para pagamento.
codigoBarras darf 2 1:1 String Código de barras do DARF.
linkDarfPDF darf 2 1:1 String Link para download do PDF do DARF.
informacoesPagamento raiz 1 1:1 Object Grupo com vencimento e valores (presente quando cdRetorno = DARF_GERADO).
dataMaximaPagamento informacoesPagamento 2 1:1 String (date ISO 8601 - YYYY-MM-DD) Data máxima para pagamento.
valorDarfPrincipal informacoesPagamento 2 1:1 number (18,2) Valor principal.
valorDarfTotal informacoesPagamento 2 1:1 number (18,2) Valor total.
mensagem raiz 1 0:1 String Mensagem de erro.
dadosInvalidos raiz 1 0:N Array de String Campos inválidos (quando cdRetorno = DADOS_DE_ENTRADA_INVALIDOS).
