# Dados e XML NF-e ABI

Source of truth é o XML fiscal versão 1.00, validado pelos XSDs em $(System.Collections.Hashtable.SchemaRoot). O projeto não cria banco nem migração. Arquivos fiscais existentes permanecem sob ownership do ERP/UniNFe e não entram em evidence. Fixtures devem ser sintéticas, consistentes com chave modelo 77 e ambiente de homologação.
